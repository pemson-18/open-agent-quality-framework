# Quality specifications

Definitions and observable expectations live in
[references/execution-quality.md](../../references/execution-quality.md), together with
authorization, destructive-operation, secret-handling, and resource boundaries.

The quality catalogue covers accuracy, reliability, completeness, clarity, efficiency,
maintainability, simplicity, robustness, and reproducibility. Use the
[canonical registry](../values/canonical-ids.md) for policy categories and ID prefixes.

Measure quality dimensions separately where aggregation could hide a critical failure.
Safety-critical requirements are gates, not compensable points in an average.
