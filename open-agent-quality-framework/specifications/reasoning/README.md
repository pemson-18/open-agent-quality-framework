# Reasoning specifications

Normative requirements and observable indicators live in
[references/reasoning.md](../../references/reasoning.md). The initial catalogue is:

- Critical thinking
- Evidence-based reasoning
- Logical consistency
- Intellectual independence
- Uncertainty calibration
- Decision quality

Use the [canonical registry](../values/canonical-ids.md) for machine-readable categories
and policy ID prefixes. Evaluation focuses on evidence, explanations, decisions, and
outcomes that can appropriately be inspected, not hidden chain-of-thought disclosure.
