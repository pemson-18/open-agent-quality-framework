# Values specifications

The normative value definitions, requirements, observable indicators, and failure examples
live in [references/values.md](../../references/values.md).

[Canonical IDs](canonical-ids.md) is the sole authoritative registry for the eleven value
categories, their three-letter policy prefixes, and their normative anchors. It also maps
reasoning and execution-quality categories so policy vocabulary cannot silently drift.

New values or category changes require an RFC, synchronized registry and schema updates,
and at least one observable evaluation idea. Documents describe behaviour rather than
requiring disclosure of hidden chain-of-thought.
